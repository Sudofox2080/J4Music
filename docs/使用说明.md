# 使用说明

这篇文档对应 App 里「设置 → 使用说明」，内容一致，方便在仓库里直接看。
文中不出现任何真实服务器地址、口令或账号信息；凡是 `<尖括号>` 都是需要你自己填的占位。

---

## 一、第一次打开：先决定要不要在线音源

App 有两套能力，互相独立：

| 能力 | 需要什么 | 不配会怎样 |
| --- | --- | --- |
| 本地音乐、已下载歌曲、加密格式转译、歌单/收藏/下载管理 | 什么都不用配 | 全部可用 |
| 在线搜索、取播放地址、歌词、云歌单 | 一个上游 HTTP 服务（地址 + 口令） | 搜索提示未配置 |

配置位置：**设置 →「云端 · 分发会员」**

1. 「上游服务地址」填 `http://<你的地址>:<端口>`，不要带结尾斜杠。
2. 「上游访问令牌」填那个服务的 `X-J4-Token` 值（如果你用仓库里的 `tools/gateway.js`，就是启动时的 `J4_TOKEN`）。
3. 两项都非空才算配好；填完点「测试云端连通」，会分别去问网易云、QQ 音乐能不能搜到歌。

> 服务器怎么搭：见仓库根目录 `README.md` 的「配置上游」一节。

## 二、登录会员：两条路，效果不同

| 入口 | 位置 | 作用范围 |
| --- | --- | --- |
| 手机端登录 | **设置 →「其它」→ 账号与会员**（也可从播放页会员入口进） | 只影响这台手机 |
| 网页控制台登录 | **设置 →「云端 · 分发会员」→ 打开网页控制台** | 登录态存在服务器，所有连这个服务的设备共用 |

### 扫码

点开某平台的「登录」→ 出现二维码 → 用该平台官方 App 扫码 → 手机上点确认 → 这边状态自动变成「已登录」。
二维码约 3 分钟有效，过期点「刷新」或重开。

### 粘贴 Cookie（扫码扫不动时）

**网易云音乐**

1. 电脑浏览器打开 `music.163.com` 并登录。
2. F12 → Application（应用）→ Cookies → `https://music.163.com`。
3. 复制 `MUSIC_U` 与 `__csrf` 两个值，拼成：

```
MUSIC_U=<那一长串>; __csrf=<那一串>
```

**QQ 音乐**

1. 浏览器登录 `y.qq.com`。
2. 同样在 Cookies 里找 `uin`（或 `wxuin`）与 `qm_keyst`（有些版本叫 `qqmusic_key`）。
3. 拼成：

```
uin=<你的QQ号>; qm_keyst=<那一长串>
```

粘进输入框 → 「用 Cookie 登录」。整串扔进去即可，不用管顺序，多余字段会被忽略。

### 登录了还是放不了会员曲？

按顺序看三件事：

1. **播放页歌名下面那枚徽标**：显示 `SQ 无损` 说明确实拿到无损；显示 `HQ 320K` / `128K` 说明被降级了。
2. **是「会员曲」还是「付费专辑」**：后者要单独购买，会员权限拿不到，这种情况 App 会走换源兜底。
3. **网络出口**：部分平台按 IP 风控，换 Wi-Fi / 换蜂窝再试。

## 四、歌单 / 收藏 / 下载 / 本地

- **我的收藏、我的下载都是歌单页**：有头图、播放全部、随机播放；行上左滑可取消收藏或删除文件。
- **心形按钮 = 往收藏里加一首**（播放页、列表行「…」菜单里都有）。
- **新建歌单默认是云歌单**（配了服务器时）：之后增删歌曲会自动同步；也可以在歌单「…」→「上传到云端」手动推。
- **下拉刷新**：首页（重拉云端歌单 + 每日推荐）、歌单页、收藏页、下载页，都从顶部往下拉。
- **导入**：「我的歌单」右侧「+」旁的导入入口，或歌单页「…」→ 导入。支持选文件（`.json` / `.m3u` / `.csv` / `.txt`）或直接粘文本；华为音乐导出的 markdown 表格也能认（歌名 + 歌手 + 专辑 + ID 四列）。
- **分享**：歌单页「…」→ 导出文本给其它软件，会打成一段 J4 文本并弹系统分享面板。
- **下载成一张本地歌单**：下载页右上角「存为本地歌单」，断网也能整张播。

## 五、加密格式转译

支持：网易云 `.ncm`、QQ 音乐 `.qmc / .qmc0 / .qmc3 / .mflac / .mgg`、华为 `.qy2`，以及本来就是明文的 `mp3 / flac / m4a / ogg / wav`。

用法：**设置 →「音乐转译（.ncm 等）」→ 选择文件**（可多选）。输出写在下载目录下的 `transcoded/` 子目录，并自动加进「转译」歌单；原文件默认保留。

转出来是噪音或失败时，先跑一次「解码器自检」。自检全绿说明实现没问题，多半是这个文件用了更新的加密变体或文件本身损坏。

## 六、常见问题

**点了播放没声音，进度条也不动**
先看通知栏有没有播放卡片：没有 → 播放服务没起来，退出重进；有卡片但进度不动 → 多半是取不到地址（会员曲没登录），底部会提示「已改播…」或「需要会员」。

**老弹「已改播某某的《某版本》」**
你要的那首在当前平台拿不到正式地址，App 按「歌名 + 歌手」在另一个平台找了能播的版本，并如实说明换成了谁的哪一版。

**歌词和歌对不上**
先确认播放页标题是不是你要的那首。标题对、歌词错，通常是平台返回的歌词本身配错了（同名不同曲），换一个源的同名版本最稳。

**搜索一直空（尤其 QQ 音乐）**
搜索接口按出口 IP 限流，短时间连打会连续返回空。等十几秒再搜，或换个网络；自建服务器时把网关放在干净 IP 上更稳。

**下载到一半失败**
看任务行的错误文案：「版权受限」= 确实拿不到正式地址；「网络」= 点重试。已下完的文件不会因重试被删。

**通知栏没有上一首/暂停/下一首**
Android 13+ 需要「通知」权限：系统设置 → 应用 → J4Music → 通知；再把电池优化设为「不限制」。

**后台放一会儿就停**
电池优化不限制 + 允许后台活动；部分国产系统还要放行「自启动 / 关联启动」，并在最近任务里加锁。

**本地音乐扫不出来**
首次扫描需要「音乐与音频」权限；拒绝过就去系统设置里补授权，再回「我的 → 本地音乐」重新扫描。扫描只读媒体库，不改文件。

**换了服务器地址，之前的登录还有效吗**
登录态跟着服务器走，换地址等于换了一套账号，需要在新的控制台重新扫码；本机自己登录的那份仍保留。

**清缓存会删掉下载的歌吗**
会。「缓存管理」的清理动作删的就是已下载/缓存的音频文件，歌单和收藏保留。只想删某个文件，用下载页行上的「…」。

**扫码登录了会员，还是提示「获取不到正式版音源」**
这是本仓库最容易踩的一个坑，按下面三步排：

1. 打开网页控制台，看平台卡片是不是绿点「已登录」。灰点说明票据没存上，重新扫码或改用「粘贴 Cookie」。
2. 控制台里点「搜索测试」，搜一首会员曲（例如网易云搜「江南」）。结果里带 VIP 标记的歌如果能播放，说明服务器登录态是好的，问题在客户端缓存 —— App 里退出登录再重新进一次即可。
3. 服务器上有自检脚本，一条命令看清链路：

```bash
cd /opt/j4-gateway
J4_GATEWAY=http://127.0.0.1:8080 J4_TOKEN=<你的口令> node verify-gateway.js
```

全部 `ok` 才算通。若「服务器登录态已生效」这一项 FAIL，多半是网关转发时没把存档的票据放进请求头 —— 上游模块只认 `Cookie` 头，不认查询参数。本仓库的 `tools/gateway.js` 已经按这个规则实现，自建时别改回旧的写法。

另外：网关会**优先使用服务器上保存的那份登录态**，因为手机里可能还留着上一次登录失败时的旧票据；服务器存档为空时才用客户端自带的那份。所以「在手机里登录」和「在控制台登录」不需要二选一，控制台登一次，全端生效。
