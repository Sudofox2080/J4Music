J4Music 1.0.0

本应用在构建时链接了下列开源组件。它们各自遵循自己的许可证，此处列出以便你核对来源。

运行时框架

  • Kotlin 标准库 2.0.21 · Apache License 2.0
  • AndroidX Core KTX 1.13.1 · Apache License 2.0
  • AndroidX AppCompat 1.7.0 · Apache License 2.0
  • AndroidX Media3（ExoPlayer / Session / DataSource / Extractor / Decoder）1.5.1 · Apache License 2.0
  • OkHttp 4.12.0 · Apache License 2.0
  • KotlinX Coroutines 1.9.0 · Apache License 2.0
  • KotlinX Serialization JSON 1.8.1 · Apache License 2.0

界面层

应用的界面是一组手写的 HTML、CSS 与 JavaScript，运行在系统 WebView 中，没有引入任何前端框架或 UI 组件库。图标为内联 SVG 路径，字体使用系统字体。

音频合成示例

「离线演示集」里的四段音频由本仓库的 tools/gen_demo_audio.py 用正弦波合成，不包含任何第三方录音。它们用于在没有网络时验证播放链路。
